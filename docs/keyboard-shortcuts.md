# Keyboard Shortcuts

English | [简体中文](keyboard-shortcuts.zh-CN.md)

Dashboard shortcuts are active only when focus is outside text inputs,
textareas, selects, and content-editable fields.

| Shortcut | Action |
| --- | --- |
| `/` | Focus dashboard search, or open the project search page on small screens. |
| `n` | Create a new item in the current project. |
| `f` | Toggle filters on the list page. |
| `j` | Focus the next visible item in list, kanban, or mobile results. |
| `k` | Focus the previous visible item in list, kanban, or mobile results. |
| `g` then `h` | Go to the project overview. |
| `g` then `l` | Go to the project list view. |
| `g` then `k` | Go to the project kanban view. |
| `g` then `s` | Go to the project search page. |

When an item link is focused, press `Enter` to open it.
