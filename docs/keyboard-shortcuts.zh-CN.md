# 键盘快捷键

[English](keyboard-shortcuts.md) | 简体中文

Dashboard 快捷键只会在焦点不在输入框、文本域、选择框和 content-editable
区域时生效。

| 快捷键 | 操作 |
| --- | --- |
| `/` | 聚焦 Dashboard 搜索；小屏幕上会打开当前项目的搜索页。 |
| `n` | 在当前项目中新建事项。 |
| `f` | 在列表页展开或收起筛选面板。 |
| `j` | 聚焦列表、看板或移动端结果中的下一个可见事项。 |
| `k` | 聚焦列表、看板或移动端结果中的上一个可见事项。 |
| `g` 然后 `h` | 跳转到项目总览。 |
| `g` 然后 `l` | 跳转到项目列表。 |
| `g` 然后 `k` | 跳转到项目看板。 |
| `g` 然后 `s` | 跳转到项目搜索页。 |

事项链接获得焦点后，按 `Enter` 即可打开详情页。
